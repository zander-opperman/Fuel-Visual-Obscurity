**Fuel Visual Obscurity**

This app is used to quantify the obstruction of a panel by vegetation. The app has two main steps. The first is to calibrate the frame size and panel color. This is done on a plane photo by selecting the upper left and lower right corners. These clicks can be precisely adjusted with a control pad. All of the colors in the image are quantified using the getColorHist function from the color distance package. Then the area around the frame is analyzed for color selection. This is the most computationally expensive process so it is limited to a select area.
